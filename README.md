# AI Chat Model Prototype

## 🚀 Setup Instructions

Follow these steps to run the prototype:

### 1. Download the Notebook
Download the file **`Finished_prototype.ipynb`** from Google Drive:  
👉 [Click here to download](https://drive.google.com/file/d/1wTOxlWIbVn-MWvx4moAxODnkzuM-FP4k/view?usp=sharing)

### 2. Open in Google Colab
- Go to [Google Colab](https://colab.research.google.com/).
- Upload and open the `Finished_prototype.ipynb` notebook.

### 3. Get Your ngrok Auth Token
- Visit [ngrok Authtoken Page](https://dashboard.ngrok.com/get-started/your-authtoken).
- Create a free account (if you don’t have one).
- Copy your **Auth Token**.

### 4. Run the Notebook
- Run each code cell **in order** from top to bottom.
- When prompted for your token:
  - Paste your ngrok **Auth Token** into the box.
  - Press **Enter**.

### 5. Start the App
- In the last code block, click **Run** or **Start**.
- After it finishes, a **URL** will appear.
- Click the URL to open the **AI Chat Model** web app.

### ✅ Done!
You can now test and interact with the AI chat model directly in your browser.

---

**Tips:**
- If you encounter any errors, make sure:
  - All code cells were executed in the correct order.  
  - The ngrok token is valid and correctly pasted.  
- If issues persist, **restart your session** in Colab via  
  `Runtime → Restart session`, then re-run all cells.
